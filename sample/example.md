# My Project Plan

## Background

When AI and humans collaborate, the friction is significant. The core issue is that humans think spatially about text, while current tools force linear interaction.

## Goals

1. Create a non-invasive annotation layer for markdown files
2. Support both human and AI annotations
3. Provide visual feedback in the editor

## Implementation Notes

The metadata file approach keeps the original markdown pristine while allowing rich annotation data to travel alongside it.
